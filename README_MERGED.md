# Catatan Versi Terdahulu

Dokumen ini dipertahankan sebagai catatan historis versi gabungan yang menggunakan Groq. Konfigurasi dan instruksi di dalamnya sudah tidak sesuai dengan backend aktif, yang menggunakan Gemini API (`GEMINI_API_KEY`).

Gunakan [README.md](README.md) untuk panduan instalasi dan dokumentasi yang mengikuti kode saat ini. Untuk aturan persona dan endpoint, lihat direktori [docs](docs/).
